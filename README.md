# Googleカレンダー → Excel 変換（週間日程表）

Googleカレンダー（またはICSファイル）の予定を、A4横の週間スケジュール表（15分単位・Excel形式）に変換するブラウザアプリです。

👉 **アプリを開く**: https://slowdrift.github.io/gcal-excel-app/

## 特徴

- **サーバー不要・完全ブラウザ完結**：予定データはお使いのブラウザ内だけで処理され、外部サーバーには送信されません（通信先はご自身のGoogleアカウントとフォント/ライブラリCDNのみ）
- 毎日の作業は「出力画面」だけで完結（① 接続 → ② 期間 → ③ 確認 → ④ 出力）。基本設定は「⚙ 設定」、使い方は「❓ ヘルプ」
- A4横・1週間=1ページの印刷レイアウト（倍率は自動設定）
- ダウンロード前の確認：今週のまとめ（過去8週との比較・前回出力からの変化・要確認の件数）と処理ログ
- キーワードによる色分け（パステル7色）・文字色・強調（太字＋下線）
- プライバシー配慮の自動変換（人名→「来客あり」、指定キーワード→「予定あり」など）
- 業務報告枠リストのコピー、ダーク／ライト表示の切り替え
- 📈 振り返り（テスト運用中）：月別の比較、業務報告の履歴、段取り対象の一覧、前年同時期との比較、予定の検索

## 使い方（Google Calendar API）

1. Google Cloud Console で OAuth クライアントID（ウェブアプリケーション）を作成
2. 「承認済みの JavaScript 生成元」に `https://slowdrift.github.io` を追加
3. アプリの「⚙ 設定 ＞ 🔑 Google API の設定」にクライアントIDを保存
4. 出力画面で認証 → 期間を選んで予定を取得 → 確認 → Excelをダウンロード

※ ICSファイル読み込みでも使えます（API の設定は不要）。詳しくはアプリ内の「❓ ヘルプ」をご覧ください。

## プライバシー

- 予定データ・認証トークン・設定・前回出力の記録は、すべてお使いのブラウザ内（ローカルストレージ）にのみ保存されます
- 本アプリの提供者が利用者のデータを受け取ることはありません
