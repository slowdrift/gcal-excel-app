1. 🎯 このアプリでできること

Googleカレンダーの予定を、A4横の週間スケジュール表（Excel形式）として出力する Web アプリです。インストール不要で、ブラウザだけで動きます（パソコン・スマートフォンどちらでも利用できます）。

画面の構成

  • 出力画面（起動時）：① 接続 → ② 期間 → ③ 確認 → ④ 出力。毎日の作業はここだけで終わります
  • 📈 振り返り（右上・テスト運用中）：月別の比較、業務報告の履歴、段取り対象の一覧、予定の検索、前年同時期との比較
  • ⚙ 設定（右上）：資料タイトル・運転手・変換ルール・色・認証など、一度決めたらあまり変えないもの
  • ❓ ヘルプ（右上）：このマニュアル
  • 🌙／☀（右上）：ダーク表示とライト表示の切り替え

Excel 出力の主な特徴

  • 9:00〜17:00 の15分単位グリッドで1週間を表示。月〜金は5列、土日は末尾2行に集約
  • 17時以降の予定は「時間外」4行、9時前の予定はヘッダー行に表示
  • 最大3つのカレンダーを結合して1つの日程表に（Google API のとき）
  • キーワードによる自動色分け（業務報告・移動など。色は設定で変更可）
  • 業務報告・本会議・代表質問・一般質問は、説明欄の ①②③ を項目として自動展開
  • プライバシー配慮の自動変換（例：「○○様」→「来客あり」、「ブロック」→「予定あり」）
  • 運転手欄は曜日ごとに自動記入。終日予定で日ごとの変更・非表示も可能
  • 印刷は1週＝1ページ（A4横）になるよう倍率を自動で設定

出力前の確認

  • 📊 今週のまとめ（過去8週との比較、前回ダウンロード時からの変化、要確認の件数）
  • 🔍 処理ログ（除外・変換・誤植の可能性・移動なし・時間外などの詳細）

🔒 カレンダーの情報はブラウザの中だけで処理され、Google 以外の外部には送信されません。

2. 🌐 アプリの開き方と事前準備

アプリの開き方

公開URL https://slowdrift.github.io/gcal-excel-app/ をブラウザで開きます（ブックマークしておくと便利です）。アプリが更新されると、次に開いたときに画面上部へ🆕 お知らせバーが表示されます。内容を確認したら「確認しました（閉じる）」を押してください。

💾 設定や記録はブラウザごとに保存されます（パソコンとスマートフォン、別のブラウザでは別々）。別の端末でも同じ設定を使いたいときは「7. バックアップと引き継ぎ」を参照してください。

Google API を使うための準備（初回のみ）

  1. Google Cloud Console でプロジェクトを作成
  2. 「APIとサービス」→「ライブラリ」で Google Calendar API を有効化
  3. 「認証情報」→「認証情報を作成」→ OAuth 2.0 クライアントID（種類：ウェブアプリケーション）
  4. 「承認済みの JavaScript 生成元」に、アプリを開くURLの生成元 https://slowdrift.github.io を登録（別の場所で開く場合はそのURLの生成元も追加）

3. 🚀 毎日の使い方（出力画面）

① 接続：予定の取り込み

🔑 Google API または 📁 .icsファイル を選びます。前回使った方法が最初から選ばれています。接続（読み込み）が済むと、この欄は1行に縮みます（「切り替える」で元に戻せます）。

  • 🔑 Google API：「🔑 Googleで認証する」→ Googleアカウントでログイン（クライアントIDが未登録なら ① に案内が出ます）
  • 📁 .icsファイル：「📂 ファイルを選択」（必要なら「📂 追加ファイルを選択」で2つ目）→「✅ 読み込む」

🔑 ログインは一定時間で切れます。切れたときは自動で更新を試み、できなかった場合だけ「🔑 再ログインして続行」ボタンが出ます。

② 期間：出力する週を選ぶ

  1. 開始日：「今週」「翌週」ボタン、または ◀ ▶ で1週ずつ移動（月曜以外を選んでも月曜に補正）。金〜日に開いたときは、最初から翌週の月曜になっています
  2. 週数：1〜6週・全期間（全期間は、API では52週、.ics では最後の予定まで・最大52週）
  3. カレンダー（API のとき）：普段はプリセットが1行で表示されています。変えるときだけ「変更」を開いて選び直します（「📌 プリセット設定」で次回も同じ選択に）
  4. 「📅 予定を取得」（API）または「📅 期間で絞り込む」（.ics）をクリック

③ 確認：ダウンロード前のチェック

予定を取得すると、ダウンロード前に次の内容が表示されます。

  • 📊 今週のまとめ
    • 過去8週との比較：予定の総数と業務報告（項目数）を、過去8週の確定した件数（平均と最小〜最大）と並べ、どこまで埋まっているかを割合で表示します。これから先の週は予定が増える途中なので、割合は低めに出ます
    • 前回の出力からの変化：同じ週を前にダウンロードしていれば、その時点からの追加・削除・時間や場所の変更を一覧表示します（記録はこのブラウザに保存）
    • 期間内の祝日と、要確認の件数（運転手欄なし・移動なし・時間外・誤植の可能性・非表示の予定）
  • 🚗 運転手：今の曜日割当。「変更」で設定の運転手欄が開きます。名前が未入力の曜日は「⚠未設定」と表示されます
  • 🔍 処理ログ：除外・変換・要確認の中身。「☐ 詳細表示」をONにすると色判定の根拠や除外理由なども出ます。「📋 コピー」でクリップボードへ（不具合の相談時に便利）

④ 出力

  1. 必要ならファイル名（基本名）を調整。実際のファイル名は「基本名＋作成日（YYYYMMDD）.xlsx」です（「📌 プリセット保存」で次回も同じ基本名に）
  2. 「⬇ Excelをダウンロード」で保存（スマートフォンでは画面下に固定表示）
  3. 任意：「👁 プレビュー」で出力イメージを確認（ブラウザでの近似表示のため、行の折り返し位置などは Excel と異なることがあります）
  4. 任意：「📋 業務報告枠リスト」で業務報告の時間枠をコピー

📋 業務報告枠リストとは？　出力日以降の平日について、業務報告イベントの時間枠を日付ごとに一覧にし、コピー用のテキストとして出力します（例：5/19（月）9:00〜10:00）。45分以下の枠には （△） が付き、枠がない平日は「業務報告枠なし」と表示されます。祝日は含みません。「知事業務報告」は対象外（副知事分のみ）です。

4. 📈 振り返り テスト運用中

🧪 テスト運用中の機能です。集計・判定は試行中のため、数字は目安としてご覧ください（正確な内容は Google カレンダーで確認してください）。Excel の出力には影響しません。

使い方

  1. 出力画面の ① 接続を済ませる（Google API で認証、または .ics ファイルを読み込む）
  2. 右上の「📈 振り返り」を開き、上の操作バーで対象の月（◀ ▶）と期間（月／四半期／年度／前年度）を選んで「集計」
  3. 集計したあとは、月・期間・タブを切り替えるだけで表示が変わります（必要なデータが足りないときだけ自動で取り直します）

タブの内容

  • 概要：予定の総数・業務報告（項目数）・段取り対象を数字のカードで表示し、前月（四半期なら前四半期）と前年同期との増減を ▲▼ で示します。その下に注目ポイント（前年同期との大きな差、2回以上報告のある課のうち90日以上報告のない課、前年同時期の行事のうち今年まだ無いもの）を自動で表示し、「見る →」で該当のタブへ移れます。月別の推移（今年度と前年度の棒グラフ）と、四半期・年度累計の詳細（開いて見る）もあります
  • 業務報告：説明欄から課・案件・担当者・内線・上席を読み取り、課ごとに報告回数・最終報告日・直近の案件を並べます。課の行を開くと、報告ごとの内容が見られます。2回以上報告のある課を上に、報告1回の課は最下部にまとめて表示します（回数は報告の回数。同じ日の報告で複数項目あっても1回）。同じ課・同じ案件の2回目以降には「再」が付きます
  • 段取り：段取り対象の予定を日付順に一覧（場所・担当課・担当者・内線つき。月や年度で見るときは月ごとに区切ります）
  • 前年比較：前年の同じ時期にあった段取り対象の予定を1件ずつ、今年の同じ日付の前後1か月で探します。見つからないものを「今年まだ登録がない行事（要確認）」として、「前年の日付 → 今年の目安（前年と同じ曜日の日）」とともにカードで表示します。見つかったものは「今年も登録済み」（開いて見る）に入ります。タイトルは年度・回数・日付・かっこ書き・法人の種類（例：「令和7年度」「R7」「第3回」「株式会社」）を除いて比べるので、表記が少し変わっても同じ行事と判定できます。「取締役会」「総会」など段取り対象のキーワードが両方に入っているときは、それを除いた部分（会社名・団体名など）で比べるので、「○○株式会社取締役会」と「△△株式会社取締役会」は別の行事として扱います
  • 検索：タイトル・場所・説明欄をキーワードで検索（スペースで区切ると、すべてを含む予定に絞り込み）。期間は上の操作バーで切り替えます

一覧のタブでは、右上の「⬇ CSV」で Excel で開けるファイルに保存できます。

業務報告の読み取り方

  • 「○○部長　○○課（案件）担当者（内線）」の形から、課・案件・担当者・内線・上席を取り出します
  • 「○○部長　○○課」「○○部長、○○次長　○○課」のように上席が付いていても、○○課としてまとめます（上席は記録として表示）
  • 「◆◆部長」のように役職名だけの項目は、集計から除きます（今週のまとめの業務報告数も同じ）
  • ①より前に書かれた前置き（例：「報告事項」）は項目として数えません
  • 内線は全角数字（例：（１２３４））でも読み取ります
  • 課名が無く「総務部長（組織改正について）」のように役職名と案件だけの項目は、役職名（総務部長）を課の代わりにしてまとめます
  • 課名が読み取れない項目は「（課名なし）」にまとめ、原文を表示します
  • CSV では、「=」「+」「-」「@」で始まる文字の先頭に「'」を付けています（Excel が数式として扱わないように）

段取り対象とは

式典や総会など、準備（段取り）が要る予定です。タイトルの語で次のように決めます（3つとも ⚙設定 ＞ 📈 段取り対象の判定 で変更できます）。

  • 対象にするキーワード：タイトルに「大会・式典・総会・懇親会・会議・表彰・祝賀・開会・記念・レセプション・取締役会・理事会・表敬」などを含む予定は対象です
  • 説明欄に記入があるときだけ対象にする語：「来訪」「面談」を含む予定は、説明欄に何か書いてあるときだけ対象です（段取りが要る予定には、担当者名や補足がほぼ必ず書かれるため）
  • 対象にしない語：「業務報告」「移動」「予定あり」「ブロック」「本会議」「議会開会」を含む予定は、上の語を含んでいても対象外です。「業務報告」は欄から消しても対象外のままです

説明欄に「〇〇課　〇〇係長（1111）」のような担当者表記もある予定は ★（確度高）として表示します。あとから初期値に足された語は、自分で変更した欄にも自動で足されます（自分で消した語は戻りません）。

※ 月別サマリーの件数は時刻指定のある予定だけを数えます（終日予定は除く）。複数カレンダーで重複する予定は1件にまとめます。

📤 段取り管理アプリ用ファイルの保存（連携）テスト運用中

  • ⚙設定 ＞ 🔗 段取り管理アプリ連携 をONにした人にだけ、出力画面の ④ に「📤 段取り管理アプリ用ファイルを保存」ボタンが出ます（既定はOFF。OFFの人の画面は変わりません）
  • 押すと、今日から6か月先までの段取り対象を 段取り取込用_YYYYMMDD.json に保存します。押すたびにカレンダーから取り直します。タイトル（先頭の「●」も含めそのまま）・日時・場所・担当課・担当者・内線と、Googleの予定IDが入ります
  • 段取り管理アプリの「📤 データ ▾」→「📥 カレンダーアプリから取り込み」で読み込むと、🆕新規／似た予定あり／取り込み済み に分けて確認してから登録できます。同じ予定は予定IDで見分けるので、何度保存して取り込んでも二重にはなりません
  • Google API で接続したときだけ使えます（.ics ファイルでは予定IDが取れないため）
5. ⚙️ 設定（右上の「⚙ 設定」）

設定はこのブラウザに自動保存され、次回以降も使われます。

🌓 表示モード

「OSの設定に合わせる」「ライト」「ダーク」から選べます。右上の 🌙／☀ ボタンでもすぐ切り替えられます。

📄 資料タイトル

Excel の各週ヘッダーに表示される名称です（例：「○○副知事週間日程表」）。空欄なら「週間日程表」になります。日付の範囲は自動で付きます。

🚗 担当運転手

A・B 2名の名前を入力し、月〜金それぞれにどちらが担当か（または「なし」）を割り当てます（「✏️ 編集する」から）。

  • 祝日・年末年始の閉庁日（12/29〜1/3）は自動で非表示
  • その日だけ変えたいときは、Googleカレンダーに終日予定を入れます
    • 田中運転手（または 田中運転手対応）→ その日の運転手名を「田中」に変更
    • 運転手なし（運転手無し・運転手不要 も可）→ その日は運転手欄を出さない
    • 田中運転手※対応なし → ※以降の文言（「対応なし」）をそのまま表示。※の後を空にすると非表示
  • 土日に予定があるときは、土日欄に「※○○運転手対応」の注記が付きます。その日に終日予定 田中運転手 を入れておくと「※田中運転手対応」と実際の名前になり、運転手なし なら注記は付きません
  • 祝日以外の理由で運転手欄が出ない曜日があると、処理ログ「🚙」に曜日と理由が表示されます

※ 終日予定による指定は Google API で取り込んだときだけ働きます（.icsファイルでは終日予定が読み込まれないため）。

🔒 タイトル変換ルール（プライバシー配慮）

特定のキーワードを含むタイトルを、別の文言に置き換えます。

  • 「出力される文言」ごとに1枚のカードを作り、その文言に変換したいキーワードをカード内にまとめます（例：カード「予定あり」に「ブロック」「議員」を登録）
  • カード内のキーワードはいずれか1つを含めば一致します。上から順に判定し、最初に一致した1枚だけを適用します（↑↓で順番を変更）
  • 適用範囲：「すべての予定」か「人名がある予定だけ」（タイトルに「○○さん・○○氏・○○様」がある予定だけ）を選べます。例：「訪問」を「人名がある予定だけ」にすると、「田中様訪問」は「訪問あり」、「○○工場訪問」はそのまま
  • カードごとに、場所が未設定のとき「※場所・送迎等確認中」を付けるかを選べます
  • どのルールにも一致しない場合、人名を含む予定は「来客あり」に変換します（チェックで ON/OFF）
  • 🧪 変換テスト：タイトルを入力すると、出力される文言と効いたルールがその場で分かります

🎨 キーワード → セル色ルール

タイトルにキーワードを含む予定の背景色・文字色・強調（太字＋下線）を決めます。背景色は白黒印刷でも読みやすいパステル7色から選びます。上から順に優先され、どれにも一致しない予定は既定の色（初期値：パステル青）になります。

初期ルール：「業務報告」→ パステル緑／「移動」→ パステル黄・赤字・太字＋下線／「予定あり」→ パステル灰

※ 色は変換前の元のタイトルで判定します。そのため「ブロック」→「予定あり」に変換された予定と、最初から「予定あり」と入力した予定では、色が変わることがあります。

🌙 時間外OK扱いキーワード

17時以降に始まる予定は処理ログに「📋 要確認」として出ます。ここに登録したキーワード（懇親会・総会など）を含む予定は、この警告を出しません。

📈 段取り対象の判定

振り返りの「段取り対象」と、段取り管理アプリ用ファイルに入れる予定を決める3つの欄です（4章「段取り対象とは」参照）。「対象にするキーワード」「対象にしない語」「説明欄に記入があるときだけ対象にする語」を、それぞれ「、」「,」または改行で区切って入力します。欄ごとの「初期値に戻す」で元に戻せます。

🔗 段取り管理アプリ連携 テスト運用中

ONにすると、出力画面に「📤 段取り管理アプリ用ファイルを保存」ボタンが出ます（4章参照）。このブラウザだけの設定で、設定ファイルの保存・復元には含まれません。

🔑 Google API の設定（クライアントID）

Google API で取り込むためのクライアントIDを登録します（「2. アプリの開き方と事前準備」参照）。

💾 設定の保存・復元

設定をファイルに保存して、別の端末や後任の方に引き継げます（「7. バックアップと引き継ぎ」参照）。

📋 出力ルール一覧（参照用）

Excel 出力の判定ルール（変換・除外・重複・誤植チェック・祝日・レイアウトなど）を一覧で確認できます。

🧰 その他

  • 🌐 ICS URL で読み込む：職場ではCORS制限により使えません
  • 🧪 テストモード：開始日を 2025-12-29、週数を全期間にセットします（動作確認用。戻すときは開始日・週数を手で変更）
6. 🖨 印刷・PDF出力

出力した Excel を印刷する

  1. ダウンロードした Excel ファイルを開き、「ファイル」→「印刷」
  2. 次の設定はアプリで設定済みなので、変更せずにそのまま印刷します
    • 用紙：A4・横方向
    • 余白：ユーザー設定の余白（上下左右 約0.4cm）
    • 拡大縮小：設定済みの倍率のまま（1週が1ページに収まるよう、週の予定量に合わせて自動で計算しています。最大70%）

⚠️ 拡大縮小を「拡大縮小なし」（100%）や「シートを1ページに印刷」に変えると、1週が複数ページに分かれたり、2週が1ページに入ったりします。拡大縮小は変更しないでください。

PDF として保存する

プリンターで「Microsoft Print to PDF」（Windows）または「PDFとして保存」（Mac）を選ぶと PDF になります。

👁 プレビュー

出力画面の「👁 プレビュー」で、Excel に書き出す前の出力イメージを新しいタブで確認できます。ブラウザでの近似表示のため、成果物の印刷・PDF化は Excel から行ってください。

📖 マニュアルを印刷する

マニュアル右上の「🖨 マニュアルを印刷」で、全章を整えた印刷用の版を新しいタブで開けます。

7. 💾 バックアップと引き継ぎ

⚙設定 ＞ 💾 設定の保存・復元 で、設定を JSON ファイルに保存（エクスポート）・読み込み（インポート）できます。

ファイルに含まれる設定

  • 資料タイトル
  • 色ルール（既定の色を含む）
  • タイトル変換ルール・人名→「来客あり」変換の ON/OFF
  • 時間外OK扱いキーワード
  • 担当運転手（A・B の名前と曜日の割当）
  • メインカレンダーのプリセット
  • 段取り対象の判定（3つの欄）

※ 含まれないもの：クライアントID、2つ目・3つ目のカレンダーとファイル名のプリセット、表示モード、ICS URL、前回の出力の記録（端末ごとの設定のため）。

引き継ぎの手順

  1. 元の端末：「📤 設定をエクスポート」→ JSON ファイルが保存される
  2. ファイルを新しい端末・後任の方に渡す
  3. 新しい端末：「📥 設定をインポート」でファイルを読み込み、確認で「OK」
  4. 運転手の曜日割当が今の設定と違う場合は、変更点（例：水 B→なし）が表示され、上書きするか選べます
  5. クライアントID は別途 ⚙設定 ＞ 🔑 で登録します

💡 設定を変えたら、その都度エクスポートして最新のファイルに置き換えておくと安心です。古いファイルを読み込むと、古い設定に戻ってしまいます。

⚠️ ブラウザのデータが消去されると設定も消えます。設定が保存されていない状態で起動すると、画面上部に案内が出ます。その場合は最新の設定ファイルをインポートしてください。

8. 🆘 トラブルシューティング

予定が取得できない

  • 🔑 Google API：⚙設定 にクライアントIDが登録されているか、ログインしたかを確認。認証エラーになる場合は、Google Cloud Console の「承認済みの JavaScript 生成元」に https://slowdrift.github.io が登録されているか確認
  • ログインの有効期限切れ：自動で更新を試みます。できなかったときは「🔑 再ログインして続行」を押してください
  • 📁 .icsファイル：zip を解凍した中の .ics ファイルを選んでいるか確認
  • 🌐 ICS URL：職場では CORS 制限で失敗します。Google API か .icsファイルを使ってください

一部の予定が Excel に出ない

  • 処理ログを確認（📅 除外された予定 🔁 重複・非表示 など）
  • 除外ルールに当たっていないか確認：タイトルが「※」で始まる／「床屋」「散髪」を含む／終日予定／平日の祝日にある予定 など（「ブロック」は除外されず「予定あり」に変換）
  • 同じ時間に3件以上重なると、3件目以降は非表示になり、1件目に「◆非表示予定あり◆」が付きます
  • 17時以降の予定は「時間外」4行に入り、5件目以降は非表示になります

運転手欄が出ない曜日がある

  • 処理ログ「🚙」に曜日と理由（曜日割当が「なし」／名前が未入力／終日予定で「運転手なし」）が出ます
  • ⚙設定 ＞ 🚗 担当運転手 で割当と名前を確認。設定ファイルをインポートした後に起きた場合は、古いファイルに「なし」が残っていた可能性があります

印刷でL列（金曜の右側）が次のページに送られる／複数ページに分かれる

  • 印刷画面の「拡大縮小」を変えていないか確認（「拡大縮小なし」や「シートを1ページに印刷」にしない）
  • 「余白」が「標準」「狭い」などに変わっていないか確認（「ユーザー設定の余白」のまま）

業務報告・議会の項目（①②③）が表示されない

  • 説明欄に ①②③ または 1. 2. 3. の形で書かれているか確認
  • 予定の長さが30分未満だと項目は展開されません

設定が消えた

  • ブラウザの履歴・サイトデータの削除などで消えることがあります。最新の設定ファイルをインポートしてください
  • 別のブラウザ・別の端末では、設定は別々です

今週のまとめ・振り返りの数字がおかしい

  • これから先の週・月は予定が増える途中なので、過去との比較では少なく見えます
  • 「前回の出力からの変化」は、このブラウザでダウンロードした記録と比べています（別の端末で出力した分は比べられません）
  • 振り返りはテスト運用中です。気づいた点があれば開発担当へお知らせください

不具合を相談したい

  • 処理ログの「☐ 詳細表示」をONにして「📋 コピー」し、画面右上のバージョン番号と一緒に伝えてください
9. ❓ よくある質問（FAQ）

Q1. 取り込み方法はどれを使えばいい？

A. 通常は 🔑 Google API です（最新の予定を直接取得でき、終日予定による運転手の指定や過去との比較も使えます）。API が使えない場合は 📁 .icsファイル を使ってください。

Q2. 更新されたかどうか、何が変わったかを知りたい

A. 更新後に初めて開いたとき、画面上部のお知らせバーに変更点が表示されます。これまでの履歴は、右上のバージョン番号（例：v1.14.0）をクリックすると見られます。

Q3. 出力した Excel を編集してもいい？

A. 通常の Excel ファイルなので、追記・修正は自由です。ただし印刷の「拡大縮小」は変えないでください（6章参照）。

Q4. 色を変えるには？

A. ⚙設定 の「🎨 キーワード → セル色ルール」で「✏️ ルールを編集する」から変更できます。

Q5. 特定の予定名を資料に出したくない

A. ⚙設定 の「🔒 タイトル変換ルール」で、出したい文言（例：「予定あり」）のカードにキーワードを追加してください。「🧪 変換テスト」で結果を確認できます。

Q6. 終日予定で運転手を変更・非表示にするには？

A. その日に終日予定で 田中運転手（名前を変更）、運転手なし（非表示）、田中運転手※対応なし（※以降をそのまま表示）と入れます（5章参照）。Google API で取り込んだときに働きます。

Q7. タイトルに「議員」を含む予定で警告が出る

A. 「議員」を含む予定は、処理ログに「📋 議員含む・要確認」と出ます。資料に出したくない場合は、タイトル変換ルールに追加してください。

Q8. 「（三役）」付き予定の時間が出ない

A. タイトルに「（三役）」を入れ、説明欄に 知事 10:00-10:30、副知事 10:30-11:00 のように時間を書いてください。セルの末尾に「※知事 10:00-10:30 / 副知事 10:30-11:00」が付きます（予定の長さが30分以上のとき）。

Q9. 場所が「応接室」にならない

A. 場所が空欄のときの自動補完は、タイトルに「面会」「来客」を含む（→応接室）、「幹部会」を含む（→第二応接室）予定だけです。それ以外はカレンダー側で場所を入力してください。

Q10. スマートフォンでも使える？

A. 使えます。公開URLを開いてください。スマートフォンでは「⬇ Excelをダウンロード」が画面下に固定表示されます。設定はパソコンとは別に保存されるので、必要なら設定ファイルをインポートしてください。

Q11. データはどこかに送信される？

A. すべてブラウザの中で処理されます。カレンダーの情報は Google から直接取得し、それ以外の外部には送信されません。設定や記録もこのブラウザの中に保存されます。

Q12. 動作するブラウザは？

A. 最新の Chrome / Edge / Firefox / Safari です（Internet Explorer は非対応）。

10. 📝 Googleカレンダー入力のコツ（出力品質を高める書き方）

このアプリは Googleカレンダーのタイトル・場所・説明欄を読み取って Excel を作ります。書き方をそろえると、自動の色分け・変換・振り返りが正しく働き、修正の手間が減ります。

📌 基本のルール

  • タイトル：1行で簡潔に。色分け・変換・段取り対象の判定に使われます。「｜」で区切ると、後ろがセルの2行目（サブタイトル）になります
  • 場所：住所または会議室名。郵便番号・「日本」・「茨城県」は自動で省きます
  • 説明欄：業務報告・議会では ①②③ で項目を並べます

✅ 良い入力例

業務報告（説明欄に項目を並べる）

タイトル：業務報告
説明：
①総務部長　人事課（職員研修について）山田係長（2101）
②財政課（補正予算について）佐藤係長（2202）
→出力：パステル緑のセルに①②で項目が並びます。振り返りの「業務報告の履歴」では、課・案件・担当者・内線に分けて記録されます（上席がいるときは先頭に役職、案件はかっこ内、末尾に担当者と内線）

式典・総会などの段取り対象

タイトル：○○協会 定期総会　場所：水戸市
説明：産業政策課　高橋係長（4101）
→振り返りの「段取り対象」に ★（確度高）付きで、担当課・担当者・内線とともに一覧されます

議会・一般質問（説明欄に質問項目を並べる）

タイトル：一般質問
説明：①○○議員：人口減少対策について　②○○議員：観光振興について
→出力：①②で議事項目が並びます

面会・来客

タイトル：○○氏 面会 または ○○様 来客（場所が空欄なら「応接室」を自動補完）
→出力：「来客あり」に自動変換（プライバシー配慮）

移動

タイトル：移動　場所：移動先（任意）
→出力：パステル黄のセルに赤字・太字＋下線（白黒印刷でも目立つ）。外出の予定の直前に「移動」がないと、処理ログ「🚗 移動なし」で知らせます

三役同席の会議

タイトル：○○会議（三役）
説明：知事 10:00-10:30　副知事 10:30-11:00
→出力：セル末尾に「※知事 10:00-10:30 / 副知事 10:30-11:00」

運転手の臨時変更（終日予定）

田中運転手 →その日の運転手名を「田中」に／運転手なし →運転手欄を出さない／田中運転手※対応なし →「対応なし」と表示

⚠️ 間違いやすい入力例

❌ 半角カナ・数字の全角半角の混在

悪い例：ｵｵﾆｼ会長 面会、第1回○○会議（第１期）
→処理ログに「⚠️ 誤植の可能性」と記録されます

❌ 業務報告の項目を「・」「-」で並べる

悪い例：・総務課　・政策企画課
良い例：①総務課　②政策企画課
→番号がないと項目として展開されません。Excel では 1. 2. の書き方も展開されますが、今週のまとめ・振り返りの項目数は ①②…の丸数字で数えるため、丸数字をおすすめします

❌ タイトルが「※」で始まる

※確認中：○○打合せ のような「※」始まりの予定は Excel に出力されません（「ブロック」を含む予定は除外されず「予定あり」に変換）。

💡 ちょっとした工夫

  • 非公開にしたい予定 → 「タイトル変換ルール」に登録すれば自動で「予定あり」などに置き換わります
  • 「○○様訪問」→ 既定の「訪問 → 訪問あり（人名がある予定だけ）」で「訪問あり」になります。迷ったら「🧪 変換テスト」で確認
  • 17時以降の懇親会など → 「時間外OK扱いキーワード」に登録すると「📋 要確認」が出なくなります
  • 段取りが必要な行事の説明欄には、担当課・担当者・内線を書いておくと、振り返りで担当者まで一覧できます。「来訪」「面談」の予定は、説明欄に何か書いてあるときだけ段取り対象になります
11. 📁 .icsファイルの書き出し手順（詳細）

Google API が使えない場合の代わりの方法です。Googleカレンダーから .ics ファイルを書き出して読み込みます。

方法A：カレンダーを1つだけ書き出す（推奨）

  1. ブラウザで Googleカレンダー を開く
  2. 左側で、書き出したいカレンダー名の右「⋮」→「設定と共有」
  3. 「カレンダーのエクスポート」をクリック → zip ファイルが保存される
  4. zip を解凍すると、カレンダー名@gmail.com.ics のような .ics ファイルが取り出せる

方法B：すべてのカレンダーをまとめて書き出す

  1. Googleカレンダー右上の「⚙」→「設定」
  2. 左側「インポート / エクスポート」→「エクスポート」
  3. すべてのカレンダーが入った zip が保存される

アプリでの読み込み

  1. 出力画面の ① 接続 で「📁 .icsファイル」を選ぶ
  2. 「📂 ファイルを選択」で .ics ファイルを選ぶ（必要なら「📂 追加ファイルを選択」で2つ目）
  3. 「✅ 読み込む」→ ② で期間を選んで「📅 期間で絞り込む」

※ .ics ファイルでは終日予定が読み込まれないため、終日予定による運転手の指定は効きません。
